# Посмотри в окно

Проектная работа по вёрстке и JavaScript. Сайт показывает видео из разных городов в разное время суток.

## Функциональность

- Загрузка данных с API Практикума.
- Фильтрация видео по городу и времени суток.
- Переключение видео по клику на карточку.
- Кнопка «Показать ещё» с пагинацией.
- Прелоадеры при загрузке видео и карточек.
- Обработка ошибок запроса с кнопкой «Обновить».

## Стек

- HTML5
- CSS3 (адаптивная вёрстка)
- JavaScript (ES6+, fetch API)
